# AirDrop

Logística aérea médica **simulada** para emergencias y reabastecimiento programado. App móvil (Flutter) + API (NestJS). Caso de estudio: Valledupar y zona cercana.

Empieza por **[INDEX.md](INDEX.md)**. El mapa de negocio está en **[context/index.md](context/index.md)**. Las reglas de implementación: **[AGENTS.md](AGENTS.md)**, [frontend/AGENTS.md](frontend/AGENTS.md), [backend/AGENTS.md](backend/AGENTS.md).

Monorepo deliberadamente simple: se sustenta en aula con buenas prácticas, sin arquitectura innecesariamente compleja.
